# sharkninja

Wireframe for the SharkNinja official brand store on Konga (Nigeria launch).

- `index.html`: the store page (navbar with Shark / Ninja dropdowns, hero carousel, shop by category, best sellers, promo banners, shop all, SEO copy). Product imagery is shown as labelled wireframe slots with the required sizes.
- `screenshots/`: desktop captures for the proposal deck (SIS section).
